# 异化体数据库前端

## 功能概览

这是一个与酒馆变量联动的异化体情报管理界面，风格为「幽灵协议」科幻终端。

### 核心功能

#### 1. 🔍 搜索功能
- **实时搜索**：在搜索框输入内容，可按编号、名称、地点快速过滤
- **清除按钮**：点击搜索框右侧的 × 按钮快速清空搜索
- **使用场景**：
  - 快速定位特定编号的异化体（如 `H-042`）
  - 按名称查找（如 `食人花`）
  - 按地点筛选（如 `废弃工厂`）

#### 2. 📊 排序功能
提供 7 种排序方式：
- **编号 ↑/↓**：按 H-XXX 编号升序/降序
- **最新/最旧记录**：按记录时间排序
- **威胁 ↑/↓**：按威胁等级排序（领主级 > 高级 > 中级 > 低级 > 未知）
- **名称 A-Z**：按异化体名称字母顺序

#### 3. ➕ 快速添加功能
- **智能编号生成**：不填编号时自动生成下一个可用编号（H-XXX 格式）
- **✨ 智能填充按钮**：自动从最新AI回复的 `<StatusBar>` 中提取：
  - `<Node>` → 记录地点
  - `<Date>` + `<Time>` → 记录时间
  - 格式转换：`2074.10.14` → `2074-10-14 18:45`
- **表单验证**：
  - 必填项：名称、分类、威胁等级
  - 可选项：地点、时间、简述（**可以留空，保存为空字符串**）
  - 防止重复编号
- **使用场景**：
  - 遭遇新异化体后立即录入情报
  - 快速补充缺失的数据库条目
  - 利用状态栏信息自动填充时间地点

#### 4. ✏️ 编辑功能
- **一键编辑**：点击每个条目右侧的编辑图标
- **实时同步**：修改后自动同步到酒馆变量
- **编号锁定**：编辑时不允许修改编号（避免数据混乱）
- **使用场景**：
  - 更新已有情报的详细信息
  - 修正错误的分类或威胁等级
  - 补充简述内容

#### 5. 🗑️ 删除功能
- **安全删除**：在编辑模态框中点击红色「删除」按钮
- **二次确认**：弹出确认对话框，防止误删
- **即时生效**：删除后立即从数据库移除
- **不可撤销**：删除操作无法恢复，请谨慎使用
- **使用场景**：
  - 清理重复或错误的条目
  - 移除无效的测试数据
  - 删除已失效的情报

#### 6. 📈 详细统计面板
点击工具栏的饼图图标展开/收起统计面板，提供两个维度的数据可视化：

**威胁等级分布**
- 显示各威胁等级的数量和占比
- 彩色进度条可视化（领主级为红色，高级为橙色等）

**地点分布 TOP5**
- 显示出现次数最多的前 5 个地点
- 蓝色进度条表示相对频率

**使用场景**：
- 评估当前区域的整体威胁水平
- 识别异化体高发区域
- 辅助制定探索路线

## 使用指南

### 添加新条目

1. 点击工具栏的 **[+]** 按钮打开添加表单
2. 填写必填项：**名称**、**分类**、**威胁等级**
3. （可选）点击 **「智能填充」** 按钮自动提取状态栏信息
4. （可选）手动填写地点、时间、简述
5. 点击 **「添加记录」** 保存

> **提示**：编号留空会自动生成下一个编号

### 编辑已有条目

1. 点击条目右侧的 **编辑图标**
2. 修改需要更新的字段
3. 点击 **「保存修改」** 提交变更
4. 或点击 **「删除」** 移除该条目（需确认）

### 智能填充功能说明

智能填充会从**最新的AI回复消息**中查找 `<StatusBar>` 标签，并提取以下信息：

```xml
<StatusBar>
  <Path>旧金山废墟 ◈ 编号B-12污染区</Path>
  <Node>三号据点</Node>           <!-- 提取为记录地点 -->
  <Date>2074.10.14</Date>          <!-- 提取为日期 -->
  <Time>18:45</Time>               <!-- 提取为时间 -->
  <Weather>...</Weather>
  <Env>...</Env>
</StatusBar>
```

**提取结果示例**：
- 记录地点：`三号据点`
- 记录时间：`2074-10-14 18:45`

## 技术实现

### 数据存储
- 数据存储在酒馆变量 `stat_data.情报库` 中
- 使用 Mvu 框架进行数据读写
- 每 2 秒自动刷新数据（保持与其他脚本同步）

### 表单验证规则
```typescript
// 必填字段
名称: string (非空)
分类: '植物型' | '动物型' | '类人型' | '微型侵入体' | '嵌合体' | '未分类'
威胁: '低级' | '中级' | '高级' | '领主级' | '未知'

// 可选字段（允许空字符串）
记录地点: string
记录时间: string
简述: string
```

### 智能编号生成逻辑
```typescript
// 扫描现有编号：H-001, H-002, H-005
// 提取最大数字：5
// 生成新编号：H-006
```

### 状态栏解析逻辑
```typescript
// 1. 获取最新AI消息
// 2. 正则匹配 <StatusBar>...</StatusBar>
// 3. 提取 <Node>、<Date>、<Time> 标签内容
// 4. 转换日期格式：YYYY.MM.DD → YYYY-MM-DD
// 5. 组合时间字符串
```

## 故障排查

### 智能填充无效
**可能原因**：
- 最新消息不是AI回复
- 消息中没有 `<StatusBar>` 标签
- 标签格式不正确

**解决方法**：
- 确保最近一条AI回复包含完整的状态栏
- 手动填写地点和时间

### 数据未同步
**可能原因**：
- Mvu 框架未初始化
- 变量路径错误

**解决方法**：
- 等待 2 秒自动刷新
- 检查控制台错误信息
- 确认变量脚本已加载

### 删除失败
**可能原因**：
- 权限问题
- 变量锁定

**解决方法**：
- 刷新页面重试
- 检查是否有其他脚本在修改同一变量
